CommitLens AI

Flagship

Extracts measurable executive commitments from earnings calls, investor letters, and press releases into a cited, auditable ledger with a reliability score per commitment.

Six sequential agents — intake, extraction, evidence research, verification, financial risk, governance — coordinated in plain Python with no agent framework. The scoring model is deterministic by design: the language model reads language, and Python owns every number, date, and status transition. That separation is the only way this ships in a regulated environment, because every score is reproducible and every claim traces to a source.

News Automater

Autonomous pipeline: discovers news every 30 minutes, generates grounded articles with AI imagery, and pushes them through WordPress and LinkedIn adapters with no manual approval step.

A zero-token local pre-gate filters on newness, corroboration, and relevance before any paid API call is made, and syndicated wire duplicates collapse via union-find so a single story reprinted twelve times never masquerades as twelve independent sources. Hard spend ceilings enforced pre-call, a grounding audit on every draft, and an offline fixture mode for deterministic tests. Publishing adapters run mocked end-to-end; real credentials swap in at the adapter boundary.

Smart Voting System

Three-factor voter authentication: election ID verification, then OTP, then face recognition.

Local Binary Pattern face recognition over Haar cascade detection, trained per-voter at registration. Layered authentication where each factor fails closed — a design constraint that matters far more than the model accuracy in any system where the cost of a false accept is a fraudulent vote.
